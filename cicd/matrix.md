# Матричные сборки

**Когда использовать** — поддержка нескольких версий языка/ОС/зависимостей;
проверка фолбэка из таблицы «Версии» (закрепленная + предыдущая).
**Когда НЕ использовать** — «матрица ради матрицы»: один джоб на версию,
которую никто не использует.

## GitHub Actions

```yaml
name: ci
on: [push, pull_request]

jobs:
  test:
    # fail-fast: false — остальные версии продолжат проверяться,
    # даже если одна упала (полная картина за один прогон).
    strategy:
      fail-fast: false
      matrix:
        go: ["1.26", "1.27"]        # фолбэк + закреплённая
        os: [ubuntu-latest]
        exclude:                    # бессмысленные комбинации
          - go: "1.26"
            os: ubuntu-24.04-arm
    runs-on: ${{ matrix.os }}
    steps:
      - uses: actions/checkout@v4

      # Кэш на комбинацию: ключ включает версию и хэш lock-файла.
      - uses: actions/setup-go@v5
        with:
          go-version: ${{ matrix.go }}
          cache: true

      - run: go vet ./...
      - run: go test ./...

  # include — особые комбинации с доп. параметрами.
  lint:
    strategy:
      matrix:
        include:
          - go: "1.27"
            linter: golangci-lint
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-go@v5
        with:
          go-version: ${{ matrix.go }}
      - run: golangci-lint run
```

## Правила

1. **Матрица = поддерживаемые версии**: закреплённая + фолбэк (из AGENTS.md),
   не «все когда-либо».
2. **Кэш — на комбинацию**: ключ = `os + версия + хэш lock-файла`;
   без кэш-ключа матрица в N раз медленнее.
3. **`fail-fast: false`** для проверок версий: одна упавшая не скрывает другие.
4. **`max-parallel`** — если матрица большая (ОС × версии × архитекторы),
   ограничьте параллелизм под квоту runners.
5. **`exclude` — честно**: не запускайте комбинации, которые не поддерживаются.
6. **Дорогие шаги — вне матрицы**: сборка артефакта/образ — один джоб,
   матрица — только проверки (иначе N одинаковых сборок).
7. **Результат — читаемый**: имя джоба с параметрами
   (`test (go 1.26, ubuntu)`), а не `test #123`.

## Pitfalls

- **Матрица × матрица**: вложенные стратегии не существуют — плоский список
  комбинаций; 3 оси по 3 значения = 9 джобов, считайте бюджет.
- **Кэш без хэша lock-файла** — «протухший» кэш: зависимости обновились,
  кэш старый → непонятные падения.
- **fail-fast по умолчанию (true)**: упала первая версия — остальные отменены,
  вы узнаёте о проблеме с последней версией только в следующем прогоне.
- **Секреты в матрице**: `secrets.*` доступны во всех джобах матрицы —
  не выносите прод-секреты в «проверочные» комбинации.
