# React: таблицы решений

## Где держать состояние

| Что хранится | Чем | Почему не альтернатива |
|---|---|---|
| Открыто/закрыто, фокус, значение поля одного экрана | `useState` | редьюсер тут — три файла ради булева |
| Несколько связанных значений с правилами перехода (стадии, шаги, таймер) | `useReducer` | в `useState` правила перехода разъезжаются по обработчикам |
| Значение выводится из других | вычисление в рендере | копия рассинхронизируется на первом же внешнем обновлении |
| Данные с сервера (кэш, инвалидация, повтор) | библиотека кэша данных или свой стор с `useSyncExternalStore` | `useState` + `useEffect` = нет отмены, нет кэша, нет состояния ошибки |
| Состояние вне React (WebSocket-стор, `localStorage`, медиа-запрос) | `useSyncExternalStore` | подписка в эффекте пропускает обновления между рендерами |
| Нужно пережить перезагрузку страницы и поделиться ссылкой | URL (`searchParams`, `hash`) | контекст и стор не видны из адресной строки |
| Реально глобальное (тема, пользователь, права) | контекст, узкий по частоте обновления | один общий контекст перерисовывает всё приложение |
| Скрыть/показать дорогой subtree без потери ввода | `<Activity>` (19.2) | размонтирование теряет фокус, скролл и черновик |

## Как ходить за данными

| Что нужно | Берём | Комментарий |
|---|---|---|
| Разовый запрос по действию (сабмит, кнопка «Проверить») | `fetch` в обработчике с `AbortController` | эффект не нужен: событие уже обработчик |
| Данные экрана + повтор + инвалидация | библиотека кэша данных (TanStack Query и аналоги) | своя реализация = те же 300 строк и те же баги |
| Данные приходят из push-канала (WS, SSE) | стор + `useSyncExternalStore` | опрос таймером — лишняя нагрузка и лаг |
| Форма с серверными ошибками | `useActionState` | состояние «отправка/ошибка» уже встроено |
| Отмена по уходу с экрана | `AbortController` в эффекте, `signal` в `fetch` | иначе результат приедет в размонтированный компонент |
| Свой API медленный или капризный | `Promise` + `AbortSignal.timeout(ms)` | без таймаута UI висит вечно |

## Формы

| Форма | Чем | Граница |
|---|---|---|
| 1-3 поля, локальная валидация | контролируемые поля + `zod.safeParse` на сабмите | библиотека не нужна |
| Отправка с серверными ошибками, статус кнопки | `useActionState` + `useFormStatus` | состояние полёта живёт в хуке, не в `useState` |
| Многошаговый мастер | `useReducer` + состояние шага в URL | перезагрузка не должна убивать прогресс |
| Поля, зависящие друг от друга (город ← регион) | запрос в обработчике смены поля + отмена предыдущего | эффект на «изменился регион» запускает запрос дважды |
| Валидация на каждое нажатие клавиши | только синтаксис (число, длина); семантика — на blur или сабмите | «неверно» под каждой буквой мешает печатать |
| Тяжёлые сетки (редактор таблиц) | специализированная библиотека | контролируемый input на 5000 ячеек — тормоз |

## Слои тестов: что где ловится

| Слой | Инструмент | Ловит | Не ловит |
|---|---|---|---|
| Чистые функции (агрегация, парсер ответа, форматирование) | Vitest, node-окружение | логику, границы, парсинг | всё, что связано с DOM |
| Компонент | Vitest + jsdom + Testing Library | поведение, доступные роли, состояния ошибки | размеры, переполнение, анимации, реальную сетку CSS |
| Стек целиком (фронт + API + БД) | smoke-скрипт против запущенного docker-compose | контракты, CORS, авторизация, миграции | визуальное состояние |
| Разметка и размеры | настоящий браузер: `getComputedStyle`, замеры (`snippets/ui-check.md`) | наезды, кликабельность, контраст, обрезку текста | — |

jsdom не считает layout: `offsetHeight`, `getBoundingClientRect` в нём дают нули. Тест в jsdom, проверяющий «кнопка не наезжает», ничего не проверяет.

## Обновление тулчейна

| Обновление | Что ломается тихо | Что проверить |
|---|---|---|
| React 18 → 19 | `defaultProps` у функций удалён, string refs удалены, `ReactDOM.render` удалён, глобальный `JSX` в типах отсутствует, `useRef()` без аргумента — ошибка типов | `grep -rn "defaultProps\|findDOMNode\|ReactDOM.render\|JSX.Element" src` |
| Vite 6/7 → 8 (Rolldown) | объектная форма `build.rollupOptions.output.manualChunks` удалена, функция — deprecated (чанки просто перестанут делиться так, как вы думали); минификатор JS — Oxc вместо esbuild, CSS — Lightning CSS; `esbuild.supported` не поддерживается и молча игнорируется | размер и состав `dist/assets/*` до и после; `build.cssMinify` |
| Топ-level `esbuild` в конфиге | deprecated → `oxc` (`jsx: "automatic"` → `oxc.jsx: { runtime: "automatic" }`) | автоконвертация есть, но `banner`/`footer` приходится делать плагином |
| `optimizeDeps.esbuildOptions` | deprecated → `optimizeDeps.rolldownOptions` | `minify`, `treeShaking`, `define`, `loader` переезжают в другие места |
| Vitest 3 → 5 | `clearMocks: true` по умолчанию (моки чищаются перед каждым тестом); `vi.mock` внутри `describe`/функции — ошибка вместо предупреждения; `-t` матчится по полному имени через `" > "`; `vite` — peer-зависимость (yarn: ставить явно); Vitest UI — по аутентифицированному URL | `grep -rn "vi.mock(" --include=*.test.ts*` вне верхнего уровня; флаги `-t` в CI |
| `@vitejs/plugin-react` 5 → 6 | Babel убран, трансформ — Oxc; React Compiler только явным `reactCompilerPreset` + `@rolldown/plugin-babel` | v5 работает с Vite 8: плагин можно не трогать |

Порядок, который экономит время: сначала тулчейн (Vite → плагин → Vitest), потом React; две смены за один коммит не разграничить, кто именно всё сломал.
