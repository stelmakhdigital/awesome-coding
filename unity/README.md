# Unity

Целевая версия: **Unity 6.3 LTS (6000.3.x)** (закреплено и проверено на 2026-09-06).
Latest supported: 6000.6.0f1; 6.7 LTS — ожидается в 2026. Fallback: 6.0 LTS.

Целевые платформы: **кроссплатформенные игры** (PC/консоли/мобильные) и **Android**.

> Код в этом разделе — рецензирован, но **не компилируется** (нужен Unity Editor).
> Перед использованием сверяйте API с версией вашего проекта.

## Конвенции проекта

- **URP** по умолчанию (мобильные + кросс); HDRP — только high-end (см. [decisions.md](decisions.md)).
- **New Input System** (`com.unity.inputsystem`) — не legacy `Input`.
- **ScriptableObject** для данных (конфиги, таблицы, профили) — не MonoBehaviour с публичными полями.
- **Композиция**: сущность = набор маленьких компонентов, не иерархия наследования.
- **События** для связи компонентов — не `Find` + прямые ссылки.
- **Object pooling** для часто создаваемых объектов (пули, частицы, урон-текст).
- **Addressables** для динамического контента (уровни, скины, локализация).

## Android-специфика

- **IL2CPP** для release (не Mono).
- **AAB** для Google Play (APK — только sideloading/тесты).
- **Target API level** — актуальный (Play требует последних); minSdk — по аудитории.
- **ProGuard/R8**: код с рефлексией и сериализацией — проверять правила обфускации.
- Устройства: тестировать на低端/средних (не только на флагмане); thermal throttling.
